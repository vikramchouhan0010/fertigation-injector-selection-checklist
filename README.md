# Fertigation injector selection checklist (drip irrigation)

Use this before you ask any supplier to quote a fertigation system. It separates the two decisions buyers usually mix up: how the fertiliser is injected, and what the drip line can support.

## 1. Note the line first
- [ ] Main line size at the injection point (¾", 1", 1.5" or 2")
- [ ] Working pressure at that point, measured with a gauge, not assumed
- [ ] Flow in the line when all zones that share the injector run together
- [ ] Whether power is available at the pump house

## 2. Pick the method
- **Venturi injector:** a pressure difference across the injector draws the fertiliser in, so it needs no power. It suits small to medium drip and sprinkler layouts, but the injection ratio moves with line pressure.
- **Dosing pump:** holds its ratio regardless of line pressure, which matters on large or uneven layouts, but needs power.
- **Complete fertigation set:** a venturi injector with ball valves, supplied ready to install, for growers who want one item to order.

## 3. Protect the injector
- [ ] Filter upstream of the injector, and a screen on the fertiliser suction line
- [ ] Ball valves on the bypass so the injector can be isolated and cleaned
- [ ] Fertiliser tank made of a material that suits the fertiliser you use

## 4. What to send with the enquiry
Line size, working pressure, flow, number of zones, crop, fertiliser type and whether you want a set or a bare injector.
